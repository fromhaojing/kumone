# 听澜

**A native SwiftUI client for NetEase Cloud Music on macOS.**

听澜 is a lightweight music app built with SwiftUI. It connects directly to NetEase Cloud Music and provides a native macOS listening experience.

Forked from [missuo/kumone](https://github.com/missuo/kumone).
